# Peepland (Peep)

UGC voxel-платформа для **Telegram Mini Apps**: криэйторы сохраняют Чертежи (Blueprints), игроки за секунду входят в эфемерные RAM-комнаты по ссылке.

**Документы (истина):**

- [GDD.md](GDD.md) — продукт, цикл, арт (GDD 2.0)
- [TZ.md](TZ.md) — техника (TZ v2.0): WebSockets, 20 Hz, без P2P/WebRTC

Легаси «инди на двоих / WebRTC» снято с ТЗ; код P2P удаляется при следующем сетевом рефакторинге.

## Как играть (текущий прототип)

1. Откройте приложение в Telegram Mini App (или локальный dev).
2. Создайте / откройте мир по ссылке.
3. WASD + мышь (Pointer Lock) или тач-джойстики; ЛКМ ломать, ПКМ ставить.
4. Камера — только первое лицо (кроме катсцен).

## Запуск

Node ≥ 22:

```bash
npm install
npm run dev
```

`http://127.0.0.1:5173/` · `npm run typecheck` · `npm run build`

## Продакшн (VPS)

Долгоживущий Node + PM2 + Nginx (см. `scripts/vps-*.sh`, `ecosystem.config.js`).  
Живые сессии — RAM; БД — чертежи и метаданные, не поток блоков матча (TZ §1.2).
