# Peep

Альтернативная история великой стройки.

Браузерный прототип: маленький voxel-мир, двое по ссылке, ломать и ставить блоки вместе.

## Как играть

1. Нажмите **Create World**.
2. Войдите в мир, походите (WASD), прыгните (пробел).
3. ЛКМ — ломать, ПКМ — ставить, клавиши 1–5 — выбрать блок.
   На телефоне: слева джойстик, справа взгляд и кнопки Ломать / Ставить / Прыжок.
4. **Invite** копирует ссылку. Друг открывает её — оказывается в том же мире.

Прямая ссылка: `/world/<код>`.

Регистрации нет.

## Запуск

Нужны Node 22 и установленные зависимости (`npm install`).

```bash
npm run dev
```

Приложение слушает `http://127.0.0.1:5173/`.

Проверка типов: `npm run typecheck`. Сборка: `npm run build`.

## Деплой (Render)

Peep — долгоживущий Node-сервер, чтобы двое могли проверить мультиплеер на одном инстансе.

В форме Web Service:

- **Build Command:** `npm install && npm run build`
- **Start Command:** `npm start`

Node 22. Без `DATABASE_URL` миры живут в памяти процесса (двое на одном сервисе). После сна или редеплоя мир пропадает.

Чтобы постройки переживали рестарт — Environment → `DATABASE_URL` (Postgres, например Neon), затем Manual Deploy.

## Что сделано

- Главный экран: Create World / Join World
- Небольшой voxel-остров (48×24×48) с берегом и океаном до горизонта
- 5 блоков: Grass, Dirt, Stone, Wood, Sand — цвет + вершинный AO, без пиксельного атласа
- Ходьба, прыжок, вид от первого лица
- Мобильное управление: динамический джойстик, кнопки действий с автоповтором
- Ломать и ставить, хотбар на 5 блоков без ограничения по количеству
- Кирка как 3D-инструмент
- Ссылка-приглашение, комната на 2 игроков
- Синхронизация игроков и блоков; новый игрок видит уже построенное
- Сообщения: World not found / World is full / Connection lost
- Свой визуальный стиль, без ассетов Minecraft

## Чего нет (намеренно)

Крафт, еда, здоровье, мобы, чат, аккаунты, бесконечный мир, биомы, погода.

## Архитектура

Монолит: клиент на TypeScript + Three.js, серверные функции TanStack Start, Postgres.

- Клиент генерирует ландшафт по seed и накладывает правки.
- Правки блоков пишутся на сервер (`peep_edits`) — источник истины для позднего входа.
- Позиции и мгновенные правки идут по лёгкому peer-каналу (сигналинг через `/api/rtc`); если канал не собрался, позиции дублируются heartbeat’ом в `peep_presence`.
- Стойкий WebSocket на serverless-хостинге недоступен, поэтому realtime — peer-канал + короткие HTTP-запросы. Для двоих этого достаточно.

Карта мира — voxel-сетка, меш по чанкам 16×24×16 с отсечением скрытых граней. Не отдельный куб на каждый блок.

## Известные проблемы

- Pointer lock может не включиться внутри iframe; тогда камера крутится перетаскиванием.
- При жёстком NAT peer-канал может не собраться; тогда друга всё равно видно через сервер, но с большей задержкой.
- Комната на двоих; третий получит «World is full».
- Нет постоянного аккаунта персонажа.
